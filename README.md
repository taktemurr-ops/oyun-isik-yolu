# Işık Yolu · Light Path

Aynaları çevir, ışık tüm kristallere ulaşsın

Sarı kaynaktan çıkan ışık düz gider, aynaya çarpınca 90 derece döner. Bir aynaya dokununca eğimi değişir. Işık duvarlarda durur. Tüm kristaller parlayınca bölüm biter; gereksiz aynalar seni yanıltmak için oradadır.

100.000 bölüm; her bölüm üretilir ve kurallara göre doğrulanır. Özgün Oyunlar merkez uygulamasının oyunu; ortak motor: [ozgun-motoru](https://github.com/taktemurr-ops/ozgun-motoru).
